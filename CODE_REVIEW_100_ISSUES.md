# Code and documentation review: 101 issues

Reviewed September 23, 2026 against the current working tree, including its existing uncommitted changes. This is a fix backlog; no application code was changed. Priorities: **P1** = serious correctness, crash, security, or data-loss problem; **P2** = functional or tooling defect; **P3** = documentation defect. Items are grouped by area, not strictly by priority.

**Evidence:** **R** means reproduced with a focused probe; **S** means established by tracing the current source; **D** means documentation checked against the current repository; **Task** marks requested implementation work. S findings have not all been exercised through the running game. Where a failure needs a particular condition, that condition is stated.

Validation performed: compiled the current team validator and URL parser into an isolated C++ probe; exercised the Python test runner with mocked subprocess/discovery results; exercised the actual atlas packing functions with synthetic entries; checked Make's dependency behavior; ran the test linter, which reported no violations.
